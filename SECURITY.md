# Security

LakeForge currently runs a local synthetic data path. It does not hold customer data, production credentials, or cloud resources.

## Reporting

Open a GitHub issue for a security concern in this repository, or use GitHub private vulnerability reporting if it is enabled for the project. Please include the version, the component, and enough detail to reproduce the issue. Do not include live credentials in the report.

## Local credentials

`.env.example` and Docker Compose use the username and password `lakeforge` for the synthetic PostgreSQL database. That value is a local dummy. It is not a secret, and it must not be reused for any real database, cloud account, or service.

Do not commit:

- passwords or API keys
- cloud credentials or connection strings that contain secrets
- private keys or tokens
- a filled-in `.env` file

Use environment variables for local overrides. Secret stores such as Azure Key Vault are planned for a later milestone and are not part of Milestone 0.

## Data

All fleet data generated by this repository is synthetic. Do not add proprietary operational data, identifiers, or schemas.
